# Task 2 Dataset

Task 2 uses the Yelp Polarity dataset.

The experiment used:
- 200,000 examples from the official training split
- 5% of that working pool for validation
- 38,000 official test examples
- random seed 42
- maximum sequence length 256
- vocabulary size 50,000

Raw and processed dataset cache files are intentionally not committed because they are reproducible from the public dataset and would substantially increase repository size.
