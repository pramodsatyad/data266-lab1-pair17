# Independent blinded audit

Left: input. Right: translation. Target domain is in the CSV.
Rate independently before discussing with the other rater. Do not disclose architecture, checkpoint, model scores or model identity. Each rater fills their own file.

Use integers 1-5. Style: 1=no target style, 3=partial, 5=convincing target style. Content: 1=major scene loss, 3=partly retained, 5=structure and objects retained. Artifacts: 1=severe defects, 3=noticeable defects, 5=no visible defects. For ALL criteria higher is better. 2 and 4 are intermediate. Add observations in notes.
